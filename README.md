# Технофін — лендинг

Статичний сайт на HTML/CSS без збірки.

- `index.html` — головна сторінка
- `about.html` — «Про компанію»
- `reports.html` — «Фінансова звітність»
- `styles.css` — спільні стилі, `about.css` — стилі внутрішніх сторінок
- `to-top.js` — кнопка «Вгору»
- `assets/` — зображення та іконки

Щоб переглянути локально:

```bash
python3 -m http.server 8765
```

і відкрити http://localhost:8765
